# Ежедневный workflow

## В core-репозитории
1. Создавать ветку `feature/<краткая-задача>`.
2. Делать логические коммиты.
3. Прогонять минимум: `npm run lint && npm run build`.
4. Сливать в `main`.

## Частота коммитов
- Минимум 1 рабочий коммит в день.
- Избегать больших "свалок" изменений.

## Release в showcase
- Периодичность: 1 раз в неделю (или по крупной фиче).
- Через скрипт экспорта формируется свежая версия showcase.
- Далее обновляется public-репозиторий showcase.

## Шаблон сообщений коммитов
- `feat: ...`
- `fix: ...`
- `refactor: ...`
- `docs: ...`
- `chore: ...`
