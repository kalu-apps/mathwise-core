# Карта репозиториев (план)

## 1) Основной репозиторий (private)
- `math-tutor-platform-core` (приватный)
- Содержит полный проект и всю ежедневную историю разработки.

## 2) Витринные репозитории (public)

### `math-whiteboard-demo`
Фокус: интерактивная рабочая тетрадь, 2D/3D инструменты, сечения, трансформации.

### `math-realtime-lesson-demo`
Фокус: коллективные уроки, роли, приглашения, синхронизация действий.

### `math-axiom-assistant-demo`
Фокус: UI/UX AI-ассистента Аксиом + сценарии использования на платформе.

## Принцип синхронизации
- Источник правды: только `core`.
- Showcase обновляются релизными срезами из `core`.
- Никакой параллельной разработки только в showcase.
- Для каждого showcase обязателен `CHANGELOG.md` (только стабильные релизные изменения).
